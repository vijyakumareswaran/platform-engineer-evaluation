# Debugging Skipped Tasks in Airflow

## Root Causes
1. **Trigger Rules**: Default `all_success` skips if any upstream task fails/skips.
2. **depends_on_past**: If `True`, a previous failure causes the current run to skip.
3. **Branching Logic**: Incorrect branching in `BranchPythonOperator`.

## Debug Steps
1. Check task logs:
   ```bash
   airflow tasks test <DAG_ID> <TASK_ID> <EXECUTION_DATE>
2.Verify trigger rules in Graph View.

3.Query metadata DB:

sql
SELECT state, trigger_rule FROM task_instance 
WHERE dag_id = '<DAG_ID>' AND task_id = '<TASK_ID>';
